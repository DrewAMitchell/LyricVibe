LyricVibe / Timing studio

Score delivery

Lyrics are retrieved automatically. An optional endpoint on your hardware can supply prepared scores for an exact YouTube video.

GET /v1/youtube/<videoId>/score · JSON score v1 · 404 falls back to lyric lookup. The request sends the video ID. Audio stays in this browser.

Browser analysis

Enable analysis from the timing editor while the source tab plays. The first run downloads model data, approximately 145 MiB for WebGPU or 39 MiB for the CPU fallback, plus runtime assets. Inference stays local. Audio is held temporarily and discarded; scores persist locally.

Current model suggestions require review. Singing confidence and overlapping vocalist separation have not been validated.
