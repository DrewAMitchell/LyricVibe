# Filtered development history

This branch preserves all 301 development commit entries after upstream `cf83a72b76bbf311d4ba8deda995edffcf9a7f7f`, followed by the public packaging commit. Author and committer timestamps and commit topology are preserved. GitHub noreply attribution replaces the personal email address; public co-author trailers remain.

Excluded from every rewritten development revision:

- song data and capture/analysis exports;
- screenshots, rendered demonstrations and audio/video recordings;
- private operational notes, resumption records and session traces;
- workstation paths, live-browser identifiers and machine-specific probe scripts;
- personal author email and identifiable music examples in retained fixtures.

Short synthetic text is still needed to test lyric parsing, timing and display. The licensed general-purpose pronunciation dictionary, Unicode keyword data and upstream icons remain. General language resources are not song-data collections.

Some evidence-only commits have empty diffs. Their presence preserves chronology; it does not imply that private verification artifacts were published. The original unfiltered history and the old-to-new commit map are retained privately by the maintainer. Only the filtered branch is intended for public updates.
